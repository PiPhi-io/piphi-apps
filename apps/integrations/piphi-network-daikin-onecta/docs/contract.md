## Automation Command Payload

`POST /command` accepts the Core automation runtime contract:

```json
{
  "contract_version": "automation.runtime.command.v1",
  "command": "refresh",
  "target": {
    "config_id": "onecta-account",
    "device_id": "piphi-network-daikin-onecta:climate-opaque-id",
    "entity_id": null
  },
  "params": {},
  "capability": "refresh",
  "capability_requirements": ["refresh"]
}
```

`refresh` performs one account-wide read. `set_target_temperature` requires
`params.target_temperature_c`, an exact climate device ID, and configuration
opt-in. It rejects stale, unavailable, read-only, wrong-target, out-of-range,
off-step, and fan-out requests before sending a single provider PATCH.
