# KNX 0.2.3 release evidence

Version `0.2.3` supersedes `0.2.2` by adding immutable OCI source, revision,
and version labels supplied by the protected release workflow. The runtime
continues to execute as UID/GID `10001` and now explicitly declares its
writable `/app/data` state volume.

Release acceptance requires:

- a `linux/amd64` and `linux/arm64` OCI index;
- GitHub provenance attestation tied to the release workflow;
- exact-digest labels matching the source repository, merge revision, and
  version `0.2.3`;
- healthy startup with a read-only root filesystem, dropped capabilities,
  `no-new-privileges`, and an initialized writable state volume;
- registry governance remaining `draft`, `unverified`, and rollout `0`.

Physical KNX interfaces, field buses, telegram interoperability, electrical
paths, firmware, and installation-specific datapoints remain unverified.
