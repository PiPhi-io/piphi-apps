# Runtime Contract

The parent is the sole entity and behavior owner. `/health` is public; every
operational surface is runtime-authenticated. Production profiles carry a
canonical SHA-256 digest and HMAC-SHA256 trust-anchor signature. Writes are an
independent default-off policy and never expand the signed allow-list.

For serial profiles, Core installs `piphi-modbus-rtu-sidecar >=0.8.1,<0.9.0`,
injects one shared dedicated sidecar token and profile trust anchor into both
processes, provides private service DNS, and grants only the selected stable
`/dev/serial/by-id/...` adapter path to the sidecar.

Generated by `piphi-network-create`.

- Integration ID: `piphi-network-modbus`
- Kind: `integration`
- Preset: `protocol-bridge`
- Domain: `bridge`
- Port: `4222`

## Required Endpoints

- `GET /health`
- `GET /entities`
- `POST /command`
- `POST /config`
- `GET /ui-config`

## Automation Command Payload

`POST /command` accepts the Core automation runtime contract:

```json
{
  "contract_version": "automation.runtime.command.v1",
  "command": "refresh",
  "target": {
    "config_id": "demo-device",
    "device_id": "demo-device",
    "entity_id": null
  },
  "params": {},
  "capability": "device.refresh",
  "capability_requirements": ["device.refresh"]
}
```

Return `{"ok": true, ...}` for accepted commands. For validation failures, return `{"ok": false, "error": "unsupported_capability", "message": "..."}` with an appropriate 4xx status.
