# Camera Stream 0.1.7 release evidence

Version `0.1.7` supersedes the unregistered `0.1.6` image by adding immutable
OCI source, revision, and version labels supplied by the protected release
workflow. The image continues to run as non-root UID `10001`.

Release acceptance requires:

- a `linux/amd64` and `linux/arm64` OCI index;
- GitHub provenance attestation tied to the release workflow;
- exact-digest OCI labels matching the source repository, merge revision, and
  version `0.1.7`;
- healthy startup with a read-only root filesystem, dropped capabilities, and
  `no-new-privileges`, using an initialized writable ledger volume owned by
  UID/GID `10001`;
- registry governance remaining `draft`, `unverified`, and rollout `0`.

Physical cameras, credentials, RTSP/RTSPS interoperability, firmware, browser
playback, and field compatibility remain explicitly unverified.
