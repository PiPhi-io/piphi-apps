# Runtime Contract

Generated by `piphi-network-create`.

- Integration ID: `piphi-camera-stream`
- Kind: `integration`
- Preset: `protocol-bridge`
- Domain: `local-device`
- Container port: `8090`; Core assigns the host port
- Onboarding: manual RTSP URL configuration with optional separate camera
  username and password fields; no device discovery
- Required shared camera media service: `piphi.service.webrtc-sidecar` `>=0.3.6,<0.4.0`
- Initial configuration succeeds only after `ffprobe` authenticates and finds a video stream.
- Availability targets a 15-second cycle and uses bounded concurrency (four probes by default).
  Cycles never overlap, so a large or slow fleet may take longer than the target interval. The
  `refresh` command probes its selected source immediately.

## Required Endpoints

Only `GET /health` is unauthenticated. Every other endpoint requires the bound
`X-PiPhi-Integration-Token` (and `X-Container-Id` when assigned); production fails closed when
identity is missing from the service environment.

- `GET /health`
- `GET /entities`
- `POST /command`
- `POST /config`
- `GET /ui-config`

## Automation Command Payload

`POST /command` accepts the Core automation runtime contract:

```json
{
  "contract_version": "automation.runtime.command.v1",
  "command": "refresh",
  "target": {
    "config_id": "demo-device",
    "device_id": "demo-device",
    "entity_id": null
  },
  "params": {},
  "capability": "device.refresh",
  "capability_requirements": ["device.refresh"]
}
```

Return `{"ok": true, ...}` for accepted commands. For validation failures, return `{"ok": false, "error": "unsupported_capability", "message": "..."}` with an appropriate 4xx status.

## Private camera endpoints

Core accesses these routes with `X-PiPhi-Integration-Token` and the assigned container identity.
Responses use `Cache-Control: no-store`; RTSP descriptors are treated as secrets.

- `GET /v1/cameras/{config_id}/source` returns the RTSP source only to the Core-to-sidecar path.
- `GET /v1/cameras/{config_id}/snapshot` returns one bounded `image/jpeg` frame with
  `Cache-Control: no-store`.

Neither endpoint is a browser-facing resource. Core must proxy user access without forwarding the
camera URL or credentials.

Keep `manifest.json`, the contract source file, and route handlers in sync.

Register one upstream reader with `starter.state.provide(...)` and publish
normalized snapshots with `starter.state.publish(...)`. The Runtime Kit owns
`GET /state`, refresh request IDs, receipts, timeouts, and unsupported refreshes.
Never implement that protocol by hand or relabel cached state as refreshed.
