# PiPhi BACnet and Home Assistant BACnet: capability and quality audit

> **Historical baseline:** This audit describes the generated scaffold before the bounded Kaiterra SenseEdge Mini implementation added on 2026-11-16. It remains as design rationale and a record of rejected unsafe scope. For current reachable behavior, use `README.md`, `capability-catalog.json`, and executable tests. Automated exact-image simulator qualification is the release gate; physical-device testing is optional follow-up evidence.

**Research cutoff:** 2026-11-16

**PiPhi source audited:** `piphi-network-bacnet` 0.1.0 source, tests, manifest, capability catalog, container, CI and release metadata in this repository

**Home Assistant baseline:** Core snapshot [`76823177f8d296dbbf017fe59627757b695e71d5`](https://github.com/home-assistant/core/tree/76823177f8d296dbbf017fe59627757b695e71d5/homeassistant/components/flexit_bacnet), official documentation snapshot [`b86ad8850f807f39580b5a6636967d96178f1214`](https://github.com/home-assistant/home-assistant.io/blob/b86ad8850f807f39580b5a6636967d96178f1214/source/_integrations/flexit_bacnet.markdown), and exact `flexit_bacnet==2.3.2` source tag [`22d62f26a088032c4c24b9bdbf33eb2dd5d8d34c`](https://github.com/piotrbulinski/flexit_bacnet/tree/22d62f26a088032c4c24b9bdbf33eb2dd5d8d34c)

**Method:** reachable production paths outrank labels, manifests and planned catalogs. Tests prove only the behavior they execute. Home Assistant's Integration Quality Scale (IQS) is used only as an analogy because PiPhi is not a Home Assistant Core integration. Protocol-library breadth is never credited to PiPhi unless a reachable PiPhi path calls it.

## Executive conclusion

There is **no generic, multi-vendor first-party Home Assistant BACnet integration or generic BACnet documentation at the cutoff**. That statement is deliberately narrow: Home Assistant's component tree has `flexit_bacnet` but no generic `bacnet` component, and Home Assistant does have that current first-party, device-specific **Flexit Nordic (BACnet)** integration. It is a Silver local-polling integration for particular Flexit air-handling units, not a general BACnet browser, router, BBMD, MS/TP gateway or arbitrary object client.[HA-COMPONENTS][HA-MANIFEST][HA-DOC][HA-IQS-FILE]

`piphi-network-bacnet` 0.1.0 is a **generated PiPhi runtime scaffold with BACnet-labelled plans, not a BACnet implementation**. It has no BACnet dependency at all: neither BACpypes3 nor another protocol library appears in `pyproject.toml` or `pdm.lock`. It opens no UDP, serial or Secure Connect transport; sends no Who-Is, I-Am, ReadProperty, ReadPropertyMultiple, WriteProperty or SubscribeCOV APDU; models no BACnet address, device, object or property; and owns no BBMD, foreign-device, routing, segmentation, invoke-ID, priority-array or MS/TP lifecycle.[P-PROJECT][P-LOCK][P-STATE][P-LIFECYCLE]

The catalog's BACpypes3 URL is a **design reference only**. It points to an unpinned moving branch and the package is not installed or imported. At exact upstream commit `eeb75e9`, BACpypes3 has substantial BACnet application/network machinery—Who-Is/I-Am, property services, COV, APDU segmentation, routing caches, IPv4 normal/foreign/BBMD stacks, IPv6 and BACnet/SC modules, object/property types and commandable priority arrays—but the inspected tree has no MS/TP link-layer implementation; an `MSTPAddress` parser is not an MS/TP transport.[BP3-APP][BP3-IP][BP3-COV][BP3-CMD][BP3-MSTP] None of that breadth is reachable from PiPhi.

The honest supported product slice is therefore only the generic in-memory runtime contract: accept/remove a host-shaped configuration, immediately assert `connected: true`, return a synthetic demo discovery/entity, record local events and accept a `refresh` command that only records receipt.[P-DISCOVERY][P-STATE][P-ENTITY][P-COMMAND] The catalog correctly marks every BACnet protocol group `planned` and unsafe broad surfaces `excluded`, but the manifest still claims BACnet/IP, Who-Is/I-Am discovery, multi-vendor object/property compatibility and full offline support. Those claims are not implemented.[P-CATALOG][P-MANIFEST]

**Release judgment:** keep 0.1.0 `draft`, rollout `0`, qualification `unverified` and quality `unrated`; do not present it as a working BACnet integration. The first release should be a deliberately bounded BACnet/IP client, not a simultaneous BACnet/IP, IPv6, Secure Connect, BBMD, foreign-device, router and MS/TP product. A defensible first slice is one explicitly selected local BACnet/IP interface, bounded unicast/discovery, stable device/object identity, allowlisted reads and writes for a small standard-object set, correct command priority/relinquish, connection- and freshness-derived availability, segmentation, traffic budgets, transactional reconfigure and attributed simulator plus physical-device evidence.

## Honest supported slice

### Supported now by reachable PiPhi source

| Dimension | Current support |
|---|---|
| Runtime configuration | Accepts a required free-form `host` and generic optional scaffold fields; stores configuration in process memory; removes or snapshot-syncs entries. No address/subnet/port/device-instance validation or BACnet probe occurs. |
| State and availability | Immediately records `connected: true` from configuration presence. This is synthetic state, not socket, BACnet device or point health. |
| Discovery and identity | `/discover` always returns `demo-device`; entities use runtime-generated IDs and the generic `bacnet_object` label. No Who-Is/I-Am, Device object read or `(device instance, object type, object instance)` identity exists. |
| Commands | `refresh` validates generic capability names and appends `runtime.command.received`; it does not read the network. Unknown commands fail closed. |
| Events, telemetry and diagnostics | Exposes generic local/example events, queues example `connected: true` telemetry, and reports active config IDs/counts. No APDU, COV, property quality, transport or bus diagnostic exists. |
| Safety | There is currently no protocol path that can write or flood a BACnet network. Broad writes, raw APDUs, destructive device services and safety bypasses are catalogued as excluded. |

### Not supported or not proven

- **Transport:** BACnet/IPv4, BACnet/IPv6, BACnet/SC, MS/TP, Ethernet, UDP socket binding, interface/subnet selection, NAT behavior, BBMD, foreign-device registration, routing or a managed sidecar.
- **Discovery/identity:** Who-Is/I-Am ranges, duplicate device-instance handling, routed discovery, Object_List traversal, stable device/object identity, vendor/protocol revision, PICS/BIBB interpretation or dynamic additions/removals.
- **Object/property model:** any standard or proprietary object type, BACnet application datatype, arrays/indexes, units, status flags, reliability, Out_Of_Service, access errors, optional properties or vendor-specific registries.
- **Reads/writes:** ReadProperty, ReadPropertyMultiple, WriteProperty, confirmed-service error handling, typed/ranged write allowlists, readback, write outcome, timeout policy or per-device concurrency.
- **Commandability:** priority 1–16 selection, reserved life-safety policy, Priority_Array inspection, NULL relinquish, Relinquish_Default or ownership/conflict reporting.
- **Events:** COV/COV-property subscription, lifetime renewal, cancellation, confirmed/unconfirmed notification handling, baseline suppression, sequence/deduplication, alarms or acknowledgements.
- **Large/routed traffic:** APDU capability negotiation, segmentation state machines, invoke-ID allocation, router discovery/cache invalidation, network-number conflicts, hop count or malformed-frame handling.
- **Product lifecycle:** real setup test, recovery/backoff, durable restart replay, staged reconfigure, resource shutdown, stale points, protocol-derived availability or actionable operator errors.
- **Qualification:** no BACnet simulator, captured APDU fixture, BTL-listed device, router, BBMD, foreign-device environment, MS/TP adapter/trunk, BACnet/SC hub/certificate or physical building network appears in PiPhi tests.

The UI/manifest also expose `bridge_address` and `protocol`, but `DeviceConfig` has neither field; conversely the model has generic API/base-URL/poll/service fields that the UI does not describe.[P-CONTRACT][P-SCHEMA][P-MANIFEST] This is scaffold residue, not a transport contract.

## Bus and building safety invariants

1. **No raw operational API.** Normal callers select a discovered-and-reviewed point or named action; never accept invocation-time APDU, destination, object/property identifier, priority, network number or routing override.
2. **Bound discovery.** Who-Is is operator-initiated or conservatively scheduled, limited by device-instance range, selected interface and destination network. Add jitter, cooldown and result caps; never recursively scan every routed network.
3. **One local BACnet identity.** Reserve a unique local device instance and UDP/link endpoint per runtime/network. Detect duplicate remote device instances and ambiguous paths instead of silently merging them.[BACNET-IDENTITY]
4. **Stable hierarchical identity.** Device key uses proven device identity; object key adds object type and instance; property key adds property identifier/index. Object_Name and IP address are mutable labels/paths, not primary keys.
5. **Read metadata before semantics.** Confirm object type, property datatype, units, status/reliability, protocol revision and writability. Unknown/proprietary types remain opaque and read-only until an attributed profile defines them.
6. **Explicit write allowlist.** Import/discovery never grants write permission. Each writable point has a reviewed datatype, finite/range/enum constraints, site policy and safe semantic action. Life-safety, access, elevator, fire and destructive administrative surfaces remain excluded by default.
7. **Priority ownership is explicit.** PiPhi writes only a configured non-life-safety slot, reports higher-priority preemption and relinquishes by writing NULL to its own slot. It never clears another client's slot or writes Relinquish_Default.[ASHRAE-PRIORITY]
8. **No blind write retry.** A timeout may mean the property changed and the ACK was lost. Surface an unknown outcome, then perform bounded readback where semantically valid; retries require an operation-specific idempotence policy.
9. **ACK is not physical confirmation.** A WriteProperty SimpleACK confirms service acceptance, not actuator motion or safe building state. Preserve commanded, effective and observed/feedback states separately.
10. **Bound every queue and transaction.** Cap outstanding requests per device/link, queue depth and age, APDU/request size, segment count/window/memory, COV subscriptions, startup reads and automation fanout. Reject overload rather than accumulating it.
11. **Respect slow links and routers.** Use per-link budgets and fair scheduling; an IP-to-MS/TP router does not turn a slow token bus into Ethernet. Avoid synchronized polls and large RPM bursts behind routers.
12. **BBMD/FDR is administrative.** Foreign registration uses an allowlisted BBMD, bounded TTL/renewal and explicit status; unload cancels registration. Never expose BDT/FDT mutation to ordinary automation, and never bridge broadcasts between arbitrary subnets.[BACNET-IP]
13. **Routing fails closed.** Allowlist destination networks, cap hop count and broadcast scope, detect duplicate network numbers/device instances, expire learned routes and preserve observed route/path diagnostics without auto-reconfiguring routers.
14. **COV is leased state.** Baseline before events; use finite subscriptions, renew before expiry with jitter, cancel on removal, deduplicate notifications, bound confirmed ACK handling and fall back to polling when subscription state is uncertain.[ASHRAE-COV]
15. **Transactional configuration.** Validate local interface/device identity, establish candidate transport, prove expected remote identity and perform a bounded safe read before activation. Failed reconfigure leaves the old session intact.
16. **Truthful availability.** Distinguish runtime alive, link/socket ready, FDR/SC connected, device responsive, object/property initialized and point stale. Never derive connectivity from configuration presence.
17. **Secrets and topology are private.** BACnet/SC private keys, certificates where sensitive, host addresses, device/object maps, network numbers and raw APDUs stay out of normal events/logs/diagnostics; support bundles are authenticated, minimized and redacted.
18. **No certification implication.** Library tests, simulator passes and a few physical devices do not prove all vendors or BTL certification. Qualification claims name exact hardware, firmware, topology, PICS/BIBBs and duration.[BTL]

## P0–P2 roadmap

### P0 — blockers before any working release

1. **Correct claims and gates.** Keep draft/unverified/unrated; remove or explicitly mark unimplemented BACnet/IP, Who-Is/I-Am, multi-vendor and full-offline claims. Remove production demo discovery/entities. Make CI execute lock checks, tests, validation and exact-image smoke tests; align GHCR/Docker Hub references.
2. **Freeze a bounded architecture.** Select and exact-pin a protocol library or implement the catalog's versioned sidecar. Record upstream commit/release and supported subset. BACpypes3 may be evaluated, but do not inherit its entire object/network surface and do not claim MS/TP from its address type.
3. **Implement BACnet/IP ownership.** Support one explicit local IPv4 interface and normal BACnet/IP mode first: unique local device instance, UDP endpoint lifecycle, subnet validation, per-device request serialization, bounded queues/timeouts and orderly shutdown. Leave IPv6, SC, BBMD server, FDR, routing and MS/TP unavailable initially.
4. **Implement bounded discovery and identity.** Operator-initiated Who-Is with ranges and cooldown; I-Am cache with expiry; Device object verification; duplicate instance/path conflict reporting; stable device/object/property keys; bounded Object_List traversal with indexed fallback and segmentation limits.
5. **Implement the first read slice.** Device metadata plus read-only Analog/Binary/Multistate Input/Value Present_Value, units, status flags, reliability and Out_Of_Service; ReadProperty/RPM access errors; last-good/stale/unavailable quality; polling jitter and per-link budgets.
6. **Implement segmentation and transaction safety.** Per-device APDU/segmentation capability, invoke-ID allocation, response correlation, bounded segment windows/memory and malformed/error/reject/abort handling. Test duplicate/lost/reordered segments and routed headers before generic RPM.
7. **Add safe writes only after reads are mature.** Named/profile-bound properties, typed/ranged values, configured priority, Priority_Array/Relinquish_Default awareness, NULL relinquish, no blind retry and explicit ACK/readback/feedback outcome states. Keep raw writes and life-safety/access/elevator surfaces excluded.
8. **Close lifecycle, API and privacy boundaries.** Durable config replay; candidate probe and atomic reconfigure; recovery/backoff; only minimal liveness public; authentication on all operational routes; route-enumeration and redaction tests covering hosts, IDs, topology, APDUs and future SC material.

### P1 — production quality for the bounded BACnet/IP slice

9. Add constrained static routing and/or foreign-device mode only from concrete deployment needs. Implement FDR TTL renewal/cancel/status and allowlisted network paths; do not implement BBMD table mutation.
10. Add COV for selected standard properties with baseline, finite leases, renewal jitter, deduplication, confirmed ACKs, restart resubscription, fallback polling and subscription budgets.
11. Add protocol simulators and attributed captures for identity conflicts, unknown/proprietary objects, arrays, per-property errors, command preemption/relinquish, malformed APDUs, segmentation, router loss, queue saturation, restart and reconfigure rollback. Enforce coverage, lint and strict typing.
12. Write operator documentation: interface/device-instance selection, network/firewall prerequisites, discovery limits, every supported object/property/type, priority policy, availability semantics, removal/reconfigure, privacy, troubleshooting and explicit unsupported modes.
13. Qualify at least two BTL-listed BACnet/IP controllers from different vendors plus one IP router to a downstream MS/TP device, recording model, firmware, PICS/listing, topology and soak/load results. This qualifies routed client behavior, not native MS/TP.

### P2 — demand-driven breadth

14. Add BACnet/IPv6 or BACnet/SC only with a chosen upstream's complete lifecycle, certificate/trust/rotation/redaction design, hub failover tests and qualified hardware. Do not silently downgrade SC to BACnet/IP.[BACNET-SC]
15. Add native MS/TP only through a least-privilege serial sidecar with exclusive stable adapter identity, electrical/topology prerequisites, baud/MAC/max-master configuration, token/error diagnostics, frame timing and multiple physical adapters/trunks. BACpypes3 `MSTPAddress` alone is insufficient.[BP3-MSTP][BACNET-MSTP]
16. Expand specialized object families, alarms/events, schedules, trends and files only from attributed demand and independent safety review. Keep device reinitialization, communication control, create/delete object, backup restore, network reconfiguration and safety bypasses out of normal automation.
17. Consider BBMD operation only as a separately privileged network-infrastructure product with configuration audit/rollback, BDT/FDT abuse controls and dedicated qualification—not as a checkbox in the integration.
