# Runtime Contract

This sidecar owns only authenticated serial transport, framing, arbitration,
queueing, recovery, and operational snapshots. It advertises no entities,
capabilities, commands, or behaviors. `/health` is public; all configuration and
`/v1/modbus/*` routes require the shared parent/sidecar Bearer token.

Core supplies exact stable adapter grants and restores authoritative config
snapshots after restart. Production profiles must pass digest/signature
verification before a descriptor is opened. Writes are independently disabled
by default and remain profile-ID/range/confirmation/read-back constrained.

Generated by `piphi-network-create`.

- Integration ID: `piphi-modbus-rtu-sidecar`
- Kind: `sidecar`
- Preset: `sidecar-worker`
- Domain: `sidecar-service`
- Port: `4212`

## Required Endpoints

- `GET /health`
- `GET /entities`
- `POST /command`
- `POST /config`
- `GET /ui-config`

## Automation Command Boundary

`POST /command` is retained only as a required runtime-contract endpoint. The
sidecar advertises no commands and returns `404` for every command payload.
Device actions belong to the parent integration and are translated there into
the authenticated, profile-bound `/v1/modbus/*` transport API.
