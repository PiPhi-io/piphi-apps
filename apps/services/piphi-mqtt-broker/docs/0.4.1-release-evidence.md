# MQTT broker 0.4.1 runtime vulnerability remediation

The immutable 0.4.0 release passed source and publication gates but failed the
separate exact-artifact vulnerability gate. It is not eligible for registry
synchronization and its tag was not moved or replaced.

Version 0.4.1 preserves the 0.4.0 broker behavior and remediates only the exact
runtime filesystem:

- the final image now starts from pinned Alpine 3.23.8 instead of the older Node
  base filesystem;
- the pinned Node 20 executable is copied from the build stage;
- npm, npx, and their vulnerable build/package-management dependency tree are
  absent from the runtime image;
- Mosquitto, OpenSSL, `su-exec`, and the C++ runtime remain explicitly pinned;
- synthetic container qualification asserts npm/npx absence.

The immutable 0.4.1 digest passed source CI, publication, provenance/SBOM, and
high/critical scanning on amd64 and arm64. Exact-digest runtime qualification
passed on amd64 but failed on arm64 because the final image contained the amd64
Node executable. Version 0.4.1 is therefore not eligible for registry
synchronization, and its image and release tag remain untouched.

No physical, host, deployment, disk-corruption, or field qualification is
claimed.
