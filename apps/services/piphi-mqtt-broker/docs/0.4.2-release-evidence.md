# MQTT broker 0.4.2 architecture remediation

The immutable 0.4.1 release passed vulnerability and supply-chain gates but
failed exact-digest arm64 runtime qualification. Its arm64 image contained an
x86-64 Node executable copied from the native build stage. It is not eligible
for registry synchronization, and its tag and image remain untouched.

Version 0.4.2 preserves broker behavior and separates the architecture-neutral
TypeScript build stage from a target-platform Node runtime stage. The image
build now checks the selected Node executable against `TARGETARCH` and executes
Node in the final filesystem, so a foreign or unloadable binary fails before
publication. Exact-image qualification also validates release labels with a
correct Docker template.

Version 0.4.2 must independently pass source CI, immutable publication,
high/critical scanning of both amd64 and arm64, attestation/SBOM verification,
and full exact-digest runtime qualification before registry synchronization.
No physical, host, deployment, disk-corruption, or field qualification is
claimed.
