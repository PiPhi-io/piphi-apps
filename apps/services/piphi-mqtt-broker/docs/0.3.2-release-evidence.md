# MQTT broker 0.3.2 exact-image remediation evidence

Version 0.3.2 preserves the 0.3.1 protocol and security contract while correcting immutable-image qualification findings:

- OCI source, revision, and version labels are populated from the release workflow.
- Startup qualification and the final broker process execute as `mosquitto`, not root.
- Root is retained only for the bounded entrypoint preparation needed to copy root-owned TLS secrets and establish ownership on managed persistent volumes.
- Exact-image qualification must verify the broker process UID, authenticated health round trip, secret-safe logs, multi-architecture index, and provenance attestation.

Physical and field qualification remain outside this software-only release.
