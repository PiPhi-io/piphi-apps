transport and advertises no runtime actions. This endpoint remains present only
because it is part of the common runtime route contract.

## Parent contract v1

`parent_contract_v1.py` validates the future private parent-to-sidecar boundary.
It does not execute this request yet:

```json
{
  "version": "1",
  "request_id": "request-1",
  "target": {
    "target_id": "opaque-target-lease"
  },
  "timeout_ms": 5000,
  "command": {
    "operation": "key_event",
    "key": "home",
    "repeat": 1
  }
}
```

The target is an opaque sidecar-issued identifier, never a raw serial or host.
Raw shell, intents, files, packages, forwarding, omitted targets, extra fields,
duplicate fields, and unbounded inputs are rejected.
